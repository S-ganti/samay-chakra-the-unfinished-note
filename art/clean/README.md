# Clean gameplay backgrounds

Eight background edits were made with the built-in image-generation tool, each referencing the corresponding original PNG in the parent directory. Originals are preserved. The game loads this folder; historical concept-art outputs still show their original scale figures.

Exact prompt used for every edit:

> Edit this environment painting with absolute minimal changes. Remove the ivory-cloaked person with rust-red scarf in the lower foreground completely, including scarf, shadow and their reflection if visible. Reconstruct the exact stone, vegetation, mist or water behind that figure seamlessly. Remove any other human silhouettes too, so this is an uninhabited game environment background. Preserve all architecture, ring, lighting, colors, framing, texture, dimensions, composition and detail. No new figures. This is a clean background plate for a separate animated playable character.

Outputs were visually inspected for removal of the foreground traveler and obvious duplicate human silhouettes. These remain flattened painted plates; real-time animation is applied separately by living-world.js.
